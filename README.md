# Amagi-Player: Open-Source P2P Культурный Медиаплеер

Программный комплекс на базе языка Python и фреймворка PyQt6, представляющий собой специализированный графический интерфейс для воспроизведения цифрового медиаконтента из распределенных одноранговых (P2P) сетей общего пользования.

## Назначение Проекта

Проект разработан в учебных и научно-исследовательских целях для демонстрации возможностей последовательной буферизации данных в децентрализованных сетях. Основная концепция системы — создание удобной среды для доступа к некоммерческому кинематографу, образовательным материалам и фильмам, распространяемым на бесплатной основе.

Приложение ориентировано на работу со следующими категориями контента:

* Классика мирового кинематографа, перешедшая в статус Общественного достояния (Public Domain) в связи с истечением срока действия авторских прав.
* Независимые инди-фильмы и анимация, официально публикуемые правообладателями под свободными лицензиями Creative Commons.
* Документальные и научно-популярные материалы, не предназначенные для коммерческого проката.

## Архитектура Валидации и Автоматизации

Для обеспечения сквозного, автоматического и безопасного пользовательского опыта, в архитектуру приложения заложена бесшовная цепочка обработки запросов:

1. **Глобальный поиск и Вайтлист (SQLite):** Пользователь вводит текстовое название фильма в поисковую строку. Система обращается к локальной базе данных верифицированного фонда. Если строгий режим включен (`USE_WHITELIST = True`), отображаются только разрешенные элементы.
2. **Сетевой парсинг метаданных:** Через API Кинопоиска приложение динамически затягивает обложки, описания, оригинальные названия и год выпуска фильма для отрисовки карточек контента.
3. **Автоматический поиск P2P-потока (Torrent Scraper):** При нажатии кнопки запуска движок берет верифицированное текстовое название фильма, автоматически парсит публичные трекеры/индексы, находит оптимальную раздачу и извлекает из нее magnet-ссылку без участия пользователя.
4. **Последовательный стриминг:** Полученная ссылка передается во встроенный qBittorrent, который принудительно собирает видеофайл строго по порядку байт для мгновенного старта воспроизведения.

## Технологический Стек

* Язык программирования: Python 3.10+
* Графический интерфейс: PyQt6 (Модульная архитектура, поддержка динамической смены тем оформления QSS, кастомные сигналы виджетов).
* Управление P2P-потоком: qBittorrent API (Встроенный фоновый Portable-клиент, реализующий алгоритм последовательной буферизации видеофайлов).
* Метаданные и API: API Кинопоиска Unofficial (Поиск по названию, запрос карточки фильма и локальное кэширование графических ассетов).
* Слой данных: SQLite (Репозиторный паттерн доступа, хранение истории таймкодов, таблицы вайтлиста и параметров сессии).

## Планируемая Структура Проекта

Приложение спроектировано по принципу разделения ответственности (Layered Architecture), где каждый слой полностью изолирован:

```text
amagi-player/
│
├── .gitignore              # Инструкция для исключения локального кэша и БД из Git
├── README.md               # Документация и концепция проекта
├── config.py               # Централизованное управление глобальными параметрами
├── requirements.txt        # Список сторонних зависимостей Python
├── main.py                 # Главный управляющий скрипт (Контроллер/Точка входа)
│
├── bin/                    # Папка исполняемых файлов внешних утилит
│   └── qbittorrent/        # Встроенный фоновый Portable-клиент qBittorrent
│
├── data/                   # Локальное динамическое хранилище
│   ├── cache/              # Кэшированные графические ассеты (обложки фильмов)
│   └── app_data.db         # Локальная база данных SQLite
│
├── database/               # Слой данных (Data Layer)
│   ├── connection.py       # Отказоустойчивый менеджер подключений к SQLite
│   ├── whitelist_repo.py   # Модуль проверки, фильтрации и хранения разрешенного фонда
│   ├── history_repo.py     # Модуль сохранения прогресса просмотров и таймкодов (секунд)
│   └── settings_repo.py    # Хранилище настроек сессии и активной темы интерфейса
│
├── services/               # Слой бизнес-логики (Business Logic Layer)
│   ├── torrent_service.py  # Скрытый запуск P2P-клиента, контроль стриминга и буферизации
│   ├── torrent_scraper.py  # Модуль автоматического поиска и парсинга magnet-ссылок по названию
│   └── kp_service.py       # Текстовый поиск фильмов через API и локальное кэширование обложек
│
└── ui/                     # Слой представления (Presentation Layer / PyQt6)
    ├── main_window.py      # Главный контейнер интерфейса (Header Bar + Стек экранов)
    ├── styles.qss          # Таблица стилей оформления (OLED Minimalism / Liquid Glass)
    └── widgets/            # Кастомные графические элементы управления
        ├── feed_widget.py  # Бесконечная адаптивная сетка кинопостеров
        ├── card_widget.py  # Скругленная кликабельная карточка (Обложка + Название + Год)
        ├── details_widget.py# Двухколоночный макет описания с кнопкой старта трансляции
        └── player_widget.py# OLED-панель видеоплеера с оверлеем P2P-буферизации
```
